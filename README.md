## 🚀 Featured Project

### [chatbot_ai](https://github.com/Emily0106/chatbot_ai)
A multi-tenant RAG chatbot platform for local government documents.

- Hybrid retrieval (dense + BM25 + RRF fusion) with reranking
- Evidence-first answers with enforced citations
- Role-based access, tenant isolation and SQL injection guards
- Ingestion pipeline for PDF, DOCX, Excel, CSV and images (OCR)
- Monitoring with Prometheus and Grafana

**Built with:** `Python` `FastAPI` `Qdrant` `PostgreSQL` `Redis` `Celery` `Docker`
